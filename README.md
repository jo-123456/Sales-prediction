# Sales Prediction Dashboard

## Overview

The Sales Prediction Dashboard is a Machine Learning based web application developed using Flask, Python, HTML, CSS, and Chart.js.
The project predicts weekly sales using different input factors such as temperature, fuel price, CPI, unemployment rate, and store number.

The application also provides a modern dashboard interface with charts, prediction cards, and analytics.

## Installation

### Clone Repository

```bash
git clone https://github.com/your-username/Sales-prediction.git
```

### Open Project Folder

```bash
cd Sales-prediction
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Flask App

```bash
python app.py
```
